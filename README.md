## التشغيل محلياً

المنصة ملفات ثابتة (HTML/CSS/JS) بلا أي خطوة بناء. لكنها تستخدم
وحدات ES Modules، لذا **يجب تشغيلها عبر خادم** ولن تعمل بفتح
`index.html` مباشرة من الملفات.

```bash
# أي واحد من هذه يكفي
python3 -m http.server 8000
npx serve .
php -S localhost:8000
```

ثم افتح <http://localhost:8000>

## ⚠️ حدود يجب معرفتها قبل النشر الحقيقي

هذه النسخة تعمل **بلا خادم**، وهذا يفرض قيوداً حقيقية لا تخفيها الواجهة:

### 1. الحسابات ليست آمنة

الحسابات وكلمات المرور تُحفظ في `localStorage` داخل متصفح كل مستخدم.
كلمات المرور تُخزَّن كبصمة SHA-256 مع مِلح عشوائي — أفضل من النص الصريح،
لكنه **ليس أماناً حقيقياً**:

- أي شخص يصل إلى الجهاز يستطيع قراءة البيانات.
- لا توجد حماية من هجمات التخمين.
- الحساب لا ينتقل بين الأجهزة أو المتصفحات.

**لا تستخدم هذه النسخة لبيانات حساسة.** للأمان الحقيقي، اربط خادماً:

```js
// js/config.js
auth: {
  mode: 'server',                      // بدل 'local'
  apiBaseUrl: 'https://api.example.com',
}
```

يجب أن يوفّر خادمك:

```
POST {apiBaseUrl}/auth/register  →  { user, token }
POST {apiBaseUrl}/auth/login     →  { user, token }
```

وأن يخزّن كلمات المرور بـ **bcrypt أو argon2** لا بـ SHA-256.

### 2. المساعد الذكي غير متصل بنموذج لغوي

افتراضياً يجيب المساعد من قاعدة معرفة مكتوبة داخل المنصة
(`js/data/knowledge.js`): بحث بالكلمات المفتاحية في مقالات وعيّنات
معدّة مسبقاً. الواجهة تُخبر المستخدم بذلك صراحةً.

**🔑 لا تضع مفتاح API في ملفات الواجهة أبداً** — سيكون مكشوفاً لكل زائر
ويمكن سرقته واستهلاك رصيدك. أنشئ خادماً وسيطاً يحتفظ بالمفتاح، ثم:

```js
// js/config.js
assistant: {
  endpoint: 'https://api.example.com/assistant',
}
```

العقد المتوقَّع:

```
POST {endpoint}
  { "messages": [ { "role": "user", "content": "..." } ] }
→ { "reply": "نص الإجابة" }
```

### 3. الدقة العلمية

المحتوى العلمي **مبسّط لأغراض تعليمية**. النماذج ثلاثية الأبعاد تخطيطية
تُظهر البنية والترتيب لا الأبعاد الذرية. المجهر الافتراضي محاكاة بصرية:
حقل الرؤية ومسطرة القياس محسوبان بقيم واقعية، لكن حركة العيّنات تقريب
بصري للحركة البراونية وليست نمذجة فيزيائية.

```

legacy/                 النسخة التجريبية الأصلية (محفوظة للرجوع)
```

## قرارات تقنية

**بلا مكتبات خارجية.** لا React ولا Three.js ولا أي CDN. السبب: المنصة
تبقى خفيفة، تعمل بلا إنترنت، ولا تتعطّل إذا سقط مزوّد خارجي. حتى العارض
ثلاثي الأبعاد محرّك مكتوب من الصفر على `canvas` ثنائي الأبعاد
(دوران بمصفوفتين، إسقاط منظوري، ثم ترتيب حسب العمق).

**الخلفية محسّنة بشدّة.** كانت مدمجة كـ base64 داخل HTML بحجم **2.02 ميجابايت**؛
صارت ملف WebP خارجياً بحجم **138 كيلوبايت** (توفير ٩٣٪) مع نسخ للجوال ونسخة
JPG احتياطية، ويخزّنها المتصفح مؤقتاً بدل إعادة تحميلها مع كل صفحة.

**رسوم العيّنات مولّدة برمجياً.** كل كائن يُرسم بـ SVG من مولّد عشوائي
مبذور (`js/art.js`) بدل صور جاهزة: حجم شبه معدوم، ووضوح مثالي عند أي تكبير.

**تهريب HTML افتراضي.** قالب `html` في `js/ui.js` يهرّب كل قيمة مُدرَجة
تلقائياً، فلا يستطيع اسم مستخدم أو رسالة حقن أي وسوم.

**احترام تفضيلات المستخدم.** الحركة تتوقف تلقائياً مع
`prefers-reduced-motion`، وعند إخفاء التبويب، ويدوياً من زر في الشريط
العلوي (والاختيار يُحفظ). الكثافة تنخفض تلقائياً على الأجهزة الضعيفة.

## إتاحة الوصول

- الواجهة بالكامل RTL مع عزل صحيح للنصوص اللاتينية وأرقام القياسات.
- تنقّل كامل بلوحة المفاتيح، ورابط تخطٍّ إلى المحتوى.
- تسميات `aria` على العناصر التفاعلية، وحصر التركيز داخل الحوارات.
- تباين لوني عالٍ على خلفية داكنة.
